# terrain6 新局经营闭环定向核验

本次从 `createGame(1000, 42173, 6)` 的真实新局开始：120金币、1份胡萝卜、基础仓房、初始旱田，以及种子42173实际生成的树和资源。不替换建筑、清空障碍或注入材料。单项测试共用一次真实地形准备，不扫描多种子，也不执行全仓测试。

## 已走通的路径

1. `FarmSweep` 对初始田 `b2` 的第0格生成播种命令，消耗1胡萝卜；将注入时钟推进到实际任务的成熟时间，再通过 `FarmSweep` 收割。产出2胡萝卜掉落，库存仍为0。显式 `pickupDrop` 后库存为2。
2. `ToolUseDrag` 的斧头释放路径针对真实最近的三棵树（t3、t5、t4），累计取得6木和6树种。拾取命中由CPU测试替身提供；没有伪造树或资源。
3. 在真实可用位置(2,5)逐次从库存落下4木，经 `ToolUseDrag` 锤子路径制作基础房屋；在(5,1)落下1木，制作公告牌。逐次落下一份与产品栏转移量一致，未以大批量落料绕过玩法。
4. 同一次锤子手势先经过房屋再经过公告牌，实际 `HammerTarget` / `EntityAssemblySelection` 生成完整部件快照。移动阶段不合成，释放才组成商店，房屋保留ID、公告牌消耗。
5. 实际 `commerceActions` 商店面板生成并启用“卖1”操作。出售1胡萝卜获得5金币；剩余1胡萝卜经 `FarmSweep` 再种回初始田。

最终状态：125金币、1木、6树种、0库存胡萝卜、1格正在生长的胡萝卜、基础仓房、原田地和商店、无剩余掉落。建造共消耗5木，没有购买材料或凭空补充库存。初始、收割拾取、伐木、部件建造、商店合成和最终再播种后均检查自动存档内容与当前状态一致、无未保存警告，以及导出→导入→导出字节一致。

## 验证边界

入口：`tests/terrain6-starter-loop.test.cjs`。执行：

```sh
npm run build:domain
node --test tests/terrain6-starter-loop.test.cjs
```

该项是领域规则与部分真实输入/面板命令路由的CPU回归，不是完整物理UI验收。农田命令经过 `FarmSweep`，未运行 `FarmTools` 的真实射线拾取；掉落拾取直接派发命令，未运行指针拖动；斧头、锤子经过实际 `ToolUseDrag`，但地图命中、场景节点和渲染使用测试替身。商店操作使用真实面板动作，未点击屏幕按钮。没有验证真实Cocos/WebGL显示、相机可达性、Android、GPU或手机性能，也不覆盖石磨、育苗、航运等其他经营路线。
