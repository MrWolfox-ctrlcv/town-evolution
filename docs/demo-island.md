# 演示岛

从开始页选择“游览演示岛”可进入独立试玩。它使用固定种子 42173 和源码中的模板，展示当前已开放的内容。建筑、资源、农田、产品与扩岛全部使用真实规则，不是静态道具。正式小镇与演示岛独立保存。

进入演示岛先显示可操作的村庄近景，邻近作物堆和船坞保持在手机两侧栏之间。需要探索远处山地、土丘或查看海岸全貌时，可打开“设置 → 小镇事务 → 查看全岛”，再拖动地图或缩放到目标处。返回设置或调整屏幕大小不会把正在看的位置强制改回初始镜头。标题背景仍展示完整海岛。

新模板的船坞在村庄附近从四种朝向选择最近的合法海岸，并朝海伸出栈桥。该变化只用于新建或明确确认重置的演示岛。已有演示岛中的旧船坞、备货、运输、正常小镇和手动存档不会自动搬迁或替换。

## 当前模板的测试入口

- **资源与地形**：平原、森林、山地、丘陵，192棵可砍的树和5币种树入口，以及可挖掘的天然石料与土料。另有一格已填出的真实陆地，可以放置物品；周围还有可测试填海的岸边。
- **全部现役产品**：胡萝卜、小麦、生菜、木材、石料、土料、泥和树种都有库存与可交互地堆。三种作物各有10份地堆，石料6份，树种5份。工具和产品侧栏可独立翻页。
- **田地生长**：主田保持三种作物各一格成熟、一格幼苗与三格空位。大旱田展示三种作物的成熟、青年、幼苗阶段及空格；大小水田保持空田，当前没有已开放的水田作物。等待真实15秒即可收获新种作物。出生时刻接近0的自动测试不能使用负时间，预熟作物会按合法时间继续生长。
- **开垦与灌溉**：初始仓房与主田下方保留一处2×2空地，供挖掘工具开田。水壶可将空的小田或大田灌成水田；有旱作物时会提示先收获，不会吞掉作物或强行灌水。
- **三田合成**：一组三块小旱田、一组三块小水田都已摆成缺一角的2×2布局，空出的奖励区域没有树、资源或物品阻挡。长按其中一块拖到同组另一块，可直接合成6×6大田；原作物保留，增加9格空种植位。
- **木工与建筑**：三处木材堆分别是1、2、4份，且已为锯子产物保留完整占地，可制成公告牌、箱子、基础房屋。另有三间基础房屋、一个箱子和订单板，可分别测试房屋合库房、房屋合商店、泥加房屋变住宅。已有住宅可直接移动与转向。
- **土变泥与填海**：相邻土料地堆为5+4份，拖水壶扫过这两堆后松手，实际消耗9份土料形成1份泥。另有独立的1份泥堆用于住宅，9份泥堆可拖到相邻海格填出1格陆地；船坞出海口不能被填堵。
- **仓储与扩建**：基础仓房和两座扩容仓库共80容量，初始库存34份，留出46份采收空间。把2份木材挂到基础仓房，再拖入锤子即可实际扩容。满仓保护、产品拾取/回收和地堆移动/合并可重复测试。
- **交易设施**：商店、订单板、真实临海船坞均已建好。初始库存可立即交胡萝卜订单。长按三种作物的10份地堆，拖到商店会按现有单价整堆出售，拖到船坞只备货，不会立即出售或出航。地堆直接交易不经过仓库；船坞总容量仍为16份，装不下整堆时原堆保留。船坞已有4份备货与一笔可领取货款，可先领取，再继续上货、出航并等待30秒结算。侧栏单份拖放与面板数量交易仍然可用。
- **配方与操作**：可打开[当前15项配方目录](recipe-handbook.md)和纸页，实际合成会记录新发现；旧冷藏融合不列入当前目录或发现进度。可测试建筑转向/移动、地图拖动/缩放、地堆移动/合并以及拾取和收获后的入栏反馈。

斧子、锯子、锤子、镰刀、水壶与挖掘工具当前无限耐久。砍树获得2份木材和2份树种；挖完整土丘获得9份土料；石柱每次获得1份石料。空间不足时整次操作不会发生。

## 尚未开放与兼容边界

肥料保留数量，但没有已开放用途。树种可获得、堆放与回收；种树仍使用5金币，不宣称已开放消耗树种的播种配方。新的制冷设施建造与冷藏生产尚未开放，因此演示岛不放置假装可生产的冷藏设备或凭空供应冷藏菜；旧存档的冷藏建筑、商品和配方记录仍按兼容规则保留。普通金币建造与金币扩容已经暂停，新的建筑通过当前材料配方获得。胡萝卜、小麦、生菜只能新种在旱田。水稻等水田作物尚未开放，不填入占位作物或新数值。旧档水田中已有的作物仍保留身份、计时与承诺产量，可正常收获；收获后不能再种旱作物。

## 存档与更新

演示岛与正式小镇使用不同存档。离开、读档、重置等切换遵守界面的保存与确认流程；保存失败会明确提示，不能把未保存状态当作保存成功。

模板由 `assets/scripts/domain/demo.ts` 的 `createDemoGame` 维护，版本由 `TownProfiles.ts` 中的 `DEMO_REVISION` 标记。已经玩过的演示进度不会被自动覆盖。发现新模板时只提示，玩家明确确认重置演示岛后才采用；重置保留原始数据备份且不影响正式小镇。旧版本和损坏存档同样不会被静默删除或替换。

固定种子与同一时间得到完全一致的演示快照。存档后读回会保留已砍树木、采集资源、田地合成、灌溉、住宅及填海等进度，不会重新填充测试材料。

## 验证边界

领域与存储回归覆盖模板合法性、全部现役产品/设施/地形、大小旱田与水田、生长与收获、两组三田合成、土变泥、住宅、填海、木工、仓储扩建、交易、低时间戳边界、可重复重置与正式存档隔离。生成树木时按大田完整4×4占地及缓冲区避让。

这些检查验证规则与存档，不能替代实际Cocos网页画面的布局、拖拽手感和设备性能验收。演示模板更新不引入新增自绘素材，全部使用已有游戏资源。
