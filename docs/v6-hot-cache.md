# V6 地形热区块复用（2026-11-07）

目标是避免镜头移开再移回时，把刚完成的近景、远景和接缝网格重新构造及上传。缓存只属于显示层，不改变存档或地形业务规则。

## 生命周期与预算

- 只缓存已完整发布的不可变区块，包括同一份三角网格、cell spans、海岸、支撑及拾取索引。不同细节档是独立快照，恢复时保持原子切换，未完成上传不可拾取。
- 不活动快照使用 LRU，同时限制为 **32 MiB保守账本、32项**；当自定义总账小于默认值时，缓存上限不超过总账的四分之一。空网格也计入条目上限。
- 不活动缓存记入已有 **256 MiB地表准入总账**。构造 staging 缺空间时先逐出未被当前事务借用的缓存，仍不足才走原预算失败/缩小视域恢复流程。
- GPU Mesh 随相同 CPU 网格对象保留，非活动节点隐藏；缓存命中不重新切片、创建或上传 Mesh。逐出后移除节点并 destroy Mesh，取消只释放新建 staging，不销毁借用快照。
- 取消回到原视域时，也检查仍在显示的快照是否正好匹配，避免重建未发生变化的 active 网格。
- 预算是保守准入账本，不是浏览器堆或显存实测。CPU账本逐出后，renderer在本次构造slice返回时同步释放缓存引用；驱动销毁时机、世界/树/纹理等不属于此账本。

## 失效与存档安全

- 缓存键包括区块局部版本、近/远景档、远景误差和四邻近景状态。近景构造不依赖邻块LOD，因此不额外把邻块档位写入近景键。
- 编辑、资源变化、海岸拓扑及树锚点变化，使涉及的区块缓存失效。缓存失效覆盖二圈邻域，避免先前远景接缝在当前近景模式下漏失效。
- 不用全局 revision 文本推断相等。同seed读入另一份合法存档时，仍按当前状态差异失效；换seed或销毁view清理所有CPU/GPU缓存。
- 过期事务不可提交。仍显示旧完整快照时，原有 dirty/ready 阻挡交互逻辑不变；缓存不会恢复过期的编辑前几何。
- 缓存可随时丢弃；不写入存档、不替换正式保存校验、不持久化派生几何。

## 定向验证

聚合 `npm run check`：2,205项通过、0失败/跳过，官方Cocos类型、项目/架构和222资产检查通过。最终受影响的41项短测与 `npm run demo:domain` 另行复核。

新增8项测试覆盖：

1. 冷近景→远景→热近景时相同CPU/支撑/拾取及GPU对象恢复，热回访0格重建、0上传字节。
2. 远景邻块LOD、远景误差和树锚点变更不会误用旧接缝。
3. 不在视野时的边界编辑及相同revision文本，不会复活旧几何。
4. 已借用缓存的事务取消、过期拒绝及再次恢复。
5. LRU字节/条目上限，待提交借用保护，以及先回收缓存再拒绝构造。
6. GPU逐出、上传失败与取消中每个Mesh恰好释放一次。
7. 切换未完成便回到原视域，复用原活动快照，0重建/上传。
8. 通过实际view同步入口替换同seed状态，检查新地形拾取、保存对象未修改；新seed释放全部旧Mesh。

上传测试使用Cocos调用替身和正式上传代码，记录实际调用字节。它们不是GPU耗时、浏览器帧率或手机测量。

## 保留的边界

首次世界准备与全岛冷网格仍需构造和上传；缓存耗尽后回访仍需重建。单格编辑仍合并/上传所属整块。未完成构造任务本轮仍会取消，不缓存半成品。树区块stream仍沿用原逐出方式；本轮未扩大到树缓存、拆分接缝或持久世界缓存。未推送、部署或执行Creator/Android真机验证。
