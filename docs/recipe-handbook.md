# 当前配方手册与旧档兼容

## 当前目录

手册目录、配方纸翻页与发现进度共用现役配方表。本轮共32项，每页最多4项，旧冷藏配方仍不占当前目录和发现进度。

1. 伐木留种：树木×1 + 斧子 → 木材×2。
2. 木制公告牌：木材×1 + 锤子 → 公告牌×1。
3. 木制箱子：木材×2 + 锤子 → 箱子×1。
4. 基础房屋：木材×4 + 锤子 → 基础房屋×1。
5. 房屋改库房：基础房屋×1 + 箱子×1 + 锤子 → 库房×1。
6. 房屋改商店：基础房屋×1 + 公告牌×1 + 锤子 → 商店×1。
7. 添木扩建：基础仓房×1 + 木材×2 + 锤子 → 扩容仓房×1。
8. 开垦田地：平地×1 + 挖掘工具 → 田地×1。
9. 连田成片：田地×3 → 大田地×1。
10. 引水入田：田地或大田地×1 + 水壶 → 水田×1。
11. 挖土成料：土丘×1 + 挖掘工具 → 土料×9。
12. 开采石料：石矿×1 + 挖掘工具 → 石料×1。
13. 和土成泥：土料×9 + 水壶 → 泥×1。
14. 填海造陆：泥×9 → 新土地×1。
15. 房屋改住宅：基础房屋×1 + 泥×1 + 锤子 → 住宅×1。
16. 田边收获箱：田地×1 + 箱子×1 + 锤子 → 带收获箱的田×1。
17. 箱子育苗：箱子×1 + 泥×1 + 锤子 → 育苗箱×1。
18. 树种育苗：育苗箱×1 + 树种×1 + 水壶 → 树苗×1。
19. 植树成林：树苗×1 → 树木×1。
20. 水田种稻：水田×1 + 稻谷×1 + 镰刀 → 稻谷×2。
21. 石料磨盘：石料×2 + 锤子 → 石磨×1。
22. 房屋改磨坊：基础房屋×1 + 石磨×1 → 磨坊×1。
23. 碾谷成米：稻谷×2 → 大米×1。
24. 磨麦成粉：小麦×2 → 面粉×1。
25. 木石砌窑：木材×1 + 石料×1 + 锤子 → 石窑×1。
26. 房屋改烘焙坊：基础房屋×1 + 石窑×1 → 烘焙坊×1。
27. 面粉烘焙：面粉×2 + 木材×1 → 面包×2。
28. 木制手推车：木材×3 + 锯子 → 手推车×1。
29. 仓房接入运输：基础仓房×1 + 手推车×1 + 锤子 → 运输仓×1。
30. 木制栈桥：木材×3 + 锤子 → 木栈桥×1。
31. 栈桥设置货箱与告示牌：木栈桥×1 + 箱子×1 + 告示牌×1 + 锤子 → 简易船坞×1。
32. 锯木造船：木材×4 + 锯子 → 木船×1。

未发现的现役配方仍显示问号/锁；拥有材料、初始建筑或进入演示岛都不会自动补记发现。真实成功操作才增加对应记录，失败与预览不增加次数。

## 纸张双指与按钮手势

正文和页内按钮（含图像子节点）均可作为双指缩放的起点。单指按按钮仍按原逻辑翻页、返回或关闭；第二指加入时取消按钮点击，两指后续移动、释放和取消由纸张统一处理，不会缩放结束后误翻页或关闭。正文单指拖动保留；纸外触点或第三指加入取消当前纸张手势，未知触点编号不改变正在进行的手势。窗口重排和界面销毁清理旧触点与父级监听。

`tests/handbook-gestures-ui.test.cjs` 通过真实注册监听的捕获、目标、冒泡顺序验证上述组合、取消后重试、屏边限制和DPR坐标区分，并检查展示操作不改游戏状态。节点及屏幕换算是窄适配器，不等同于真实Cocos渲染、浏览器触摸或手机验收。

目录和配方纸只响应有限、非零的竖向滚轮增量。纯横向滚动、零增量和无效值不改变纸张位置或缩放，也不会透传给后方地图；按钮图像上的滚动遵循相同规则。正常竖向缩放方向、上下限、双指与翻页按钮保持不变。
