## 如何试玩

本机已准备好实际 Cocos 预览产物。仓库根目录运行：

```sh
npm run preview:serve
```

打开 `http://127.0.0.1:4178`。服务仅监听本机。源码修改后运行 `npm run preview:build` 重建，再刷新页面。

推荐在演示岛操作：

1. 将右侧木材拖到基础仓房上，重复三次，观察屋顶材料托盘。
2. 把左侧锤子拖到该仓房上，观察扩建；三份木材会用掉两份。
3. 点选扩建后的仓房，取回剩余木材；刷新页面验证保存结果。
4. 将斧子拖到树上，将锯子拖到演示岛已有的三份木材堆上。
5. 打开右下角图鉴，查看三条已发现配方与其余线索，尝试翻页、拖动和缩放。

演示岛可在工具页明确确认后重置，与正常小镇独立保存。现有存档不会为了展示新功能而被替换。工具栏空间不足时使用侧栏翻页。船坞挂载材料后可通过“更多 / 材料”进入材料回收与货款领取页面。
