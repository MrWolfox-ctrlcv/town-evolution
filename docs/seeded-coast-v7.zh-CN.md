# 随机海岸实验（独立 terrain7）

本版新增独立预览入口“随机海岸实验”，固定初始 seed42173，生成身份 `v7-seeded-coast-1`，保存 wire12，内部 state schema10。旧1–6、normal/demo默认4、原菜单入口和原存档命名空间不迁移。没有新增物件、配方、经济数值、流体、种子编辑器或随机重开玩法。

## 权威海岸与范围

主外岸由96条闭合边、每个湾由48条闭合边组成。固定均匀角序，半径是椭圆基形加两尺度的冻结 Perlin 值；种子只决定初始几何。主岸径向扰动幅值界22格，两湾12格。实际形状未裁边，也不为失败种子减噪或换种子。固定出生/连接小半岛保留，所以不是每一段岸线都随种子变化。

对生成的闭合多边形计算精确最近边距离，并用角扇区确定内外。正半径、相邻角差及闭环角差均在(0,π)，每条边在自己的不重叠扇区内，故边界简单闭合，中心在内。点积投影夹到[0,1]，零长度/非有限边与非法坐标直接拒绝。包围盒只用距离下界跳过不可能更近的边，不改变距离结果。

同侧点到闭边界的距离为1-Lipschitz。异侧点连线必经过边界，故两距离之和不大于点距，带符号距离仍为1-Lipschitz。顶点中的Perlin只定义固定几何，不作为查询坐标的导数项。

另在有符号距离上叠加小尺度连续场噪声。冻结P除以√2，幅值≤1，解析梯度界 `B=1+15√2/4`。代码向上取6.3033008589。主岸幅度1、0.35，波长64、32，归一化L=1.16743143；两湾幅度3、1，波长40、20，L=1.787912608。两者均高于 `1+BΣ|a|/λ`。这保证归一化后的场1-Lipschitz。

除以L不改变单个场的零线。它会改变与其它场组合以及固定床面阈值对应的宽度，不能把它描述成压缩零线扰动振幅。验收数据分别检查真实床面与海面交线、完整格证书和逻辑dry场。

陆体M取归一化主岸与固定出生骨架的max；湾B取两归一化湾与两条显式水域出口胶囊的max；O=max(-M,B)。湖与原河道保持原世界坐标，河出口只加入水场。F=smoothMax(lake,river,4)，D=-smoothMax(O,F,4)。水出口不进入陆地max。max、负号和该smoothMax均保持1-Lipschitz。

## 数值保守性

新7统一epsilon=1e-5。实数场的1-Lipschitz是解析结论；有限精度guard是针对受测JavaScript浮点实现的保守工程界，不声称ECMAScript规范为任意引擎的sin/cos/atan2/hypot提供固定ULP保证。

有效查询坐标限于±1e6，生成几何约在[0,203]。平方距离不超过约2.1e12；最近边取min不累加所有边的误差。误差预算分别预留2e-6给Double几何/角扇区/噪声计算（依赖受测基本函数误差远小于64 ULP这一保守假设），海床范围内Float32转换误差不超过2^-23，剩余裕量仍在1e-5以内。扇区缝与顶点符号误分只能进入近边epsilon带，分类须失败关闭。数值对照与极值采样用于发现偏差，不代替解析证明，也不是跨引擎形式化验证。

格证书使用√(1/2)+epsilon；港口半格覆盖、freshwaterUpper、填海/船坞准入同样收紧，marine-origin准入以epsilon收紧，LOD剔除则扩大保留区。深水岸床凸包由实际Float32顶点及固定三角剖分约束。人工挖后顶面、竖壁、拾取、近远网格和桥脚仍取同一编辑表面。

## 发布前的每世界资格

资格在有界work迭代器内逐格、逐队列节点、逐树执行，未完成/取消/失败均不发布世界。检查：

- 同seed真实合法陆格至少旧terrain3的20倍，且所有合法陆格四邻接连通。
- 真正四群系、开局可编辑土石、树、初始建筑平整脚点。
- 完整格水证书构成的湖、河、两个湾口与外海连通。全部原河路径点落在该连通区域；不是仅靠几个中心点声称河连续。
- 已认证自然港，真实边缘床低于水波谷。
- 每个主岸多边形的真实顶点包围盒给出离四边最短距离δ。边段仍在此凸包内，所以边界主岸场≤(-δ+1.35)/L；再与固定骨架≤-2.25取max。该上界不满足-2.25时直接失败，不裁格、不换seed。实数D≤-2.25与单调岸床PROFILE推出床≤-0.6875，低于波谷-0.642，留0.0455几何余量。资格也把field和床面各扩大epsilon后再核此余量；浮点证书不把实数上界原封视为零误差。没有宣称所有十亿合法seed都成功。

有限核心seed1/7/42173实际自然港后的合法土地分别19328/19683/19246格；同seed旧3为934/903/899。新7只用独立可取消主线程分帧准备，不接入旧6 worker，也不宣称新7 worker与fallback等价。work单位不是毫秒或帧率保证。

## 存档与恢复

新7命名空间为 `town-evolution.v7-preview.v7-seeded-coast-1.` 前缀。公共reader严格要求wire12、terrain7、准确revision和format1编辑检查点；terrain7伪装旧wire10/11、旧世界伪装12、未来wire/revision均拒绝。写出内部schema10时先私有编码为wire12再走严格reader，不放宽公开入口。共享编辑字段仍叫terrain6，但世界身份由version与revision决定。

新7准备、手动栏位与恢复检查主档/备份/栏位原字节，遇跨页变化停止。写前保护未来primary、backup，以及将覆盖的before-reset、unreadable、manual before-overwrite目标。取消不保存旧会话；成功采用前先验证候选、保存旧会话，再保存并采用候选。任一步失败保留旧会话。所有测试用内存storage，不触真实玩家存储。

旧客户端对wire12主档会拒绝；旧程序在未来档只处于backup或旧primary+未来backup时存在既有轮换覆盖限制。新版本没有回溯修复已部署旧程序。不要手工把新7档放入旧profile或旧版本的备份键。
