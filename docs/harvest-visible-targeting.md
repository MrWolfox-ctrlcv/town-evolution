# 镰刀按可见作物格收割

## 已复现的问题

功能清单 F03 要求镰刀收割接触到的成熟小格，不误收相邻格。此前镰刀只查询每格 `±0.31` 的作物包围体。合法混种农田中，指针落在第 0 格胡萝卜的真实可见三角面上，较近小麦包围体内的空白却抢走命中：普通田提交第 4 格，大田提交第 7 格，库存增加小麦而不是胡萝卜。新增静态矩阵 24 例在原逻辑下有 22 例失败。

## 修复边界

- 播种和镰刀复用同一次真实可见表面查询，但播种的目标与规则不变。
- 镰刀先取当前世界变换下最近的可见作物三角面及其小格身份。未成熟的可见作物仍是目标，由业务规则提示未成熟，不跳到邻格。
- 树、地堆、天然资源、其它建筑和农田附件的真实遮挡都终止镰刀命中。包围体中位于遮挡物前方的空白不能绕过遮挡。
- 只有看到同一农田的土面时，才允许该田作物包围体提供叶片空隙容错。不能借其它农田、附件、完全未命中或隐藏/抬起的模型收割。随后保留该田土面小格回退，方便快速划动。
- 每个采样只遍历一次真实模型及资源，不再因镰刀未命中重复调用全场景建筑拾取。原有 3 像素插值及每次最多 256 个采样保持不变；网格表面缓存继续复用。
- 批次刷新前已收割的旧网格仍按当前可见身份挡住后格，由每格手势去重阻止重复命令。相同手势中连续同一屏幕点的 move/up 不再次收割刷新后新露出的邻格；移动或发起新手势可正常继续。
- 不改作物配方、成熟时间、每格两份产量、库存容量、存档格式或其它操作规则。

## 土面边界按同一次真实命中定位

大田的部分真实土脊位于 y=0.1865，旧播种代码却在命中后重新投射到 y=0.17。沿实际相机斜率看边界时，这个高度差会把目标挪到邻格。合法旋转演示大田 b22 后，固定土面点可复现第11格与第17格之间的误种，且错误结果会写入存档。普通田对应点的土面为 y=0.17，不受这一差值影响。

播种和收割的裸土回退现在共用 `farmCellAtHit`，直接以原射线的 `o + d × hit.distance` 解析同一可见土面点，不再生成第二条射线或假定统一土面高度。此距离是原射线参数，未单位化射线也必须使用原方向。前景作物身份、遮挡和同田叶片空隙的收割优先级保持不变。

`tests/farm-surface-cell.test.cjs` 从未修改的演示岛执行合法旋转，覆盖大小田与四朝向、固定边界点、单位/非单位射线和独立前向变换三角面的对照、精准扣一份种入目标格、邻格不变及存档重载。原逻辑下普通田四例通过、大田四例失败；修复后八例通过。测试同时禁止再次调用地图地面投射，并验证同一土面的收割回退格。它不证明物理触屏或GPU显示效果。
