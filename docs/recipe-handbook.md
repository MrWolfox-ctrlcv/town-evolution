# 当前配方手册与旧档兼容

## 当前目录

本文按 **2026-11-08 本地源码**整理。手册目录、配方纸翻页与发现进度共用现役配方表，当前共 **38 项、10 页**，每页最多 4 项，末页 2 项。旧冷藏配方仍不占当前目录和发现进度。条目及顺序以 [`recipes.ts`](../assets/scripts/domain/recipes.ts) 和 [`route-recipes.ts`](../assets/scripts/domain/route-recipes.ts) 为准。

1. 伐木留种：树木×1 + 斧子 → 木材×2 + 树种×2。
2. 木制公告牌：木材×1 + 锤子 → 公告牌×1。
3. 木制箱子：木材×2 + 锤子 → 箱子×1。
4. 基础房屋：木材×4 + 锤子 → 基础房屋×1。
5. 房屋改库房：基础房屋×1 + 箱子×1 + 锤子 → 库房×1。
6. 房屋改商店：基础房屋×1 + 公告牌×1 + 锤子 → 商店×1。
7. 添木扩建：基础仓房×1 + 木材×2 + 锤子 → 扩容仓房×1。
8. 开垦田地：平地×1 + 挖掘工具 → 田地×1。
9. 连田成片：田地×3 → 大田地×1。
10. 引水入田：田地或大田地×1 + 水壶 → 水田×1。
11. 挖土成料：土丘×1 + 挖掘工具 → 土料×9。
12. 开采石料：石矿×1 + 挖掘工具 → 石料×1。
13. 和土成泥：土料×9 + 水壶 → 泥×1。
14. 填海造陆：泥×9 → 新土地×1。
15. 房屋改住宅：基础房屋×1 + 泥×1 + 锤子 → 住宅×1。
16. 锯木做围栏：木材×1 + 锯子 → 围栏×1；占1格，可移动和旋转。
17. 锯木做长凳：木材×2 + 锯子 → 长凳×1；占1格，可移动和旋转。
18. 双栈桥跨河：木栈桥×2 → 木桥×1；在 terrain5 / terrain6 的真实河流两岸对齐后直接拖放合成，宽2格、总长7–16格。
19. 木箱改木桶：未挂材料的空箱×1 + 锤子 → 堆肥木桶×1。
20. 木桶堆肥：允许的作物或树种共2份 → 肥料×1；可混合，当前耗时15秒，手动领取，肥料用途尚未开放。
21. 石窑烤胡萝卜：胡萝卜×2 → 烤胡萝卜×1；在石窑加工，当前耗时10秒，手动领取。
22. 田边收获箱：田地×1 + 箱子×1 + 锤子 → 带收获箱的田×1。
23. 箱子育苗：箱子×1 + 泥×1 + 锤子 → 育苗箱×1。
24. 树种育苗：育苗箱×1 + 树种×1 + 水壶 → 树苗×1。
25. 植树成林：树苗×1 → 树木×1。
26. 水田种稻：水田×1 + 稻谷×1 + 镰刀 → 稻谷×2。
27. 石料磨盘：石料×2 + 锤子 → 石磨×1。
28. 房屋改磨坊：基础房屋×1 + 石磨×1 → 磨坊×1。
29. 碾谷成米：稻谷×2 → 大米×1。
30. 磨麦成粉：小麦×2 → 面粉×1。
31. 木石砌窑：木材×1 + 石料×1 + 锤子 → 石窑×1。
32. 房屋改烘焙坊：基础房屋×1 + 石窑×1 → 烘焙坊×1。
33. 面粉烘焙：面粉×2 + 木材×1 → 面包×2。
34. 木制手推车：木材×3 + 锯子 → 手推车×1。
35. 仓房接入运输：基础仓房×1 + 手推车×1 + 锤子 → 运输仓×1。
36. 木制栈桥：木材×3 + 锤子 → 木栈桥×1。
37. 栈桥设置货箱与告示牌：木栈桥×1 + 箱子×1 + 告示牌×1 + 锤子 → 简易船坞×1。
38. 锯木造船：木材×4 + 锯子 → 木船×1。

未发现的现役配方仍显示问号/锁；拥有材料、初始建筑或进入演示岛都不会自动补记发现。真实成功操作才增加对应记录，失败与预览不增加次数。加工、育苗与堆肥的时间和产量以开始任务时的承诺保存，不因后续调参改写。

目录并不表示每个地形都能完成全部配方。普通小镇与演示岛新建时仍使用 terrain4；独立“木桥演示”使用 terrain5。terrain6 已接入高差木桥，两端原栈桥内各保留2格坡道，桥面与桩按真实地形重建，不削平河岸；只支持符合高差 / 坡度限制的完整河岸和独立河段，拒绝海湖、已挖填 / 填海及其他占用。目录中的9土制1泥、9泥填1格海域是既有规则，不能代替 terrain6 的土 / 石体积结算。terrain6 及本次高差桥仍是未部署的源码集成候选，真实 Cocos / WebGL、GPU 与手机尚未验收，详见[terrain6 接入状态](terrain6-integration.md)。

工具分工以 [`craft-recipes.ts`](../assets/scripts/domain/craft-recipes.ts) 为准：公告牌、箱子、房屋、栈桥和石磨使用锤子，围栏、长凳、手推车与木船使用锯子。房屋与箱子 / 公告牌、农田与箱子、仓房与手推车，以及栈桥与箱子 / 公告牌均须明确选择实体后用锤子装配；房屋与石磨 / 石窑则直接拖放融合。生产与容器操作详见[生产路线](new-production-routes.md)，试玩材料见[演示岛](demo-island.md)。

## 旧冷藏数据保留

完整配方注册表保留 `merge-cold`，只把它标记为旧版兼容项。存档导入继续校验并保留原发现次数和首次发现时间，不删除或重命名已有记录。含围栏、长凳或相应发现的档写入 schema11，其余仍写 schema10；兼容导入 schema8/9/10/11；记录隐藏不等于重置或清除旧档。旧档中已有的制冷设施与基础仓房仍按既有规则融合，融合记录仍保存，但不再弹出不可见配方的“图鉴新发现”。

当前不开放制冷设施建造、冷藏生产或新冷藏商品。已有冷藏建筑、库存、在途货物、待领取任务与收益按既有兼容规则继续处理，不为了隐藏手册条目清除任何玩家数据。

## 纸张双指与按钮手势

正文和页内按钮（含图像子节点）均可作为双指缩放的起点。单指按按钮仍按原逻辑翻页、返回或关闭；第二指加入时取消按钮点击，两指后续移动、释放和取消由纸张统一处理，不会缩放结束后误翻页或关闭。正文单指拖动保留；纸外触点或第三指加入取消当前纸张手势，未知触点编号不改变正在进行的手势。窗口重排和界面销毁清理旧触点与父级监听。

`tests/handbook-gestures-ui.test.cjs` 通过真实注册监听的捕获、目标、冒泡顺序验证上述组合、取消后重试、屏边限制和DPR坐标区分，并检查展示操作不改游戏状态。节点及屏幕换算是窄适配器，不等同于真实Cocos渲染、浏览器触摸或手机验收。

目录和配方纸只响应有限、非零的竖向滚轮增量。纯横向滚动、零增量和无效值不改变纸张位置或缩放，也不会透传给后方地图；按钮图像上的滚动遵循相同规则。正常竖向缩放方向、上下限、双指与翻页按钮保持不变。
