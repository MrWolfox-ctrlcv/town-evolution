# 演示岛

首次打开进入“演示岛”。它使用固定种子和源码中的模板，方便展示及重复测试；不是静态截图，设施和产品执行真实业务规则。

## 已安排的测试入口

- 主农田包含三种作物的成熟、生长和空闲格；另有空农田可连续播种。
- 仓房、商店、订单板和临海船坞已建好；有库存、备货和可领取运输单。
- 有可砍的实体树、可用斧子、镰刀和锯子。
- 两处木材堆分别是三份和五份，测试建造及余料退回。
- 可打开配方文件夹、选择配方纸并拖动缩放；可测试建筑四方向转向、长按移动、地堆长按移动/合并及地图拖动缩放。
- 收获、拾取、购买和工具补充成功后，会触发来源到对应侧栏的小图标动画。
- 水壶、肥料和锤子仍是待设计工具，不将其展示成已经可用的生产配方。

## 存档与更新

“工具”页可切换演示岛与正常小镇。两者独立保存；切换前先保存当前进度，保存失败会提示。重置演示岛需要确认，不影响正常小镇。

模板由 `assets/scripts/domain/demo.ts` 的 `createDemoGame` 维护。内容更新时修改 `TownProfiles.ts` 中的 `DEMO_REVISION`。已经玩过的演示进度不会被自动覆盖；界面提示模板更新，由玩家确认重置后采用。固定种子让同一模板的海岛和设施便于比较。

本次版本按用户明确要求清理此前版本的测试存档，只处理本游戏已知存档键。当前版本进度、其他应用存储和更高版本存档不在清理范围内。旧进度的清理发生在打开新版时，不能据源码部署成功推断用户设备已经执行过。

## 验证边界

领域与存储测试可验证演示模板合法、规则可执行、模式隔离及重置范围。实际屏幕布局、拖拽手感和设备性能仍需真实浏览器或设备验收，不能用纯规则测试替代。
