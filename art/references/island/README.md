# Island and stack concept references

AI-generated concept images were viewed before implementing the corresponding art.
These are visual references, not screenshots of the game.

- `coastal-spawn-central-mountain.png`: revised 2026-11-05 island concept.
  A coastal starting settlement, central/near-central mountain, and seeded forest
  and earth hills around it replace the earlier fixed-four-region composition.
  Waterfalls and river details are concept-only and are not implemented gameplay.
- `quantity-pile-reference.png`: material/color/arrangement reference for visible
  quantities. Some generated groups contain incorrect counts. Runtime geometry
  follows the exact quantity and business stack limit, not those image counts.

Shared model recipes, category metadata, and verification notes are described in
[the natural island art guide](../../../docs/natural-island-art.md).
