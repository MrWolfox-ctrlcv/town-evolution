# 最新 v6 实际浏览器验收准备

用户当前优先级是实际验收，再处理性能，最后处理小问题。本次只补齐验收路径，没有修改游戏生产代码、存档格式、地形生成或渲染规则。代码和脚本检查不能冒充实际 WebGL、手机或 GPU 通过。

## 当前新增范围

`capture.cjs` 对桌面 1280×800 与触摸模拟 390×844 分别创建独立浏览器上下文。每个 v6 检查都从空测试资料开始，先于原有检查运行；旧演示检查失败不会阻止 v6 取证，v6 失败也不会取消旧断言。原有标题、Web Locks 等待页、演示、设置以及三轮配方检查保留。四组结果统一汇总，只要有一组失败，命令仍失败。

运行前要求构建来源与当前 Git 提交一致、构建与验收脚本没有已跟踪的未提交修改，并复核应用、Worker 和引擎的 SHA256。来源信息随截图证据保存。旧 b8a8f7f 或其他提交的预览不能当作当前源码通过。

`ui-driver.cjs` 从生产 `profileStorage` 派生正常、演示、v5、木桥和 v6 的实际存档键，避免 v6 误读演示档。还识别真实挖掘工具、回家/全岛/缩放按钮及工具分页。需要后续页的操作通过真实“更多”按钮完成，完整一轮找不到就失败，不直接调用隐藏动作。

旧远端验收曾在切换到正常小镇后等待“购买作物”超时，失败画面与标签只有主界面和设置按钮，没有小镇事务面板。根因尚未确认，不能通过再次打开面板消除失败。原演示导航顺序及购买、金额、双档隔离、重置和重载断言保留；只增加存档前、保存后、返回游戏后的面板/会话只读记录，供下一次实际运行定位问题。

## v6 真实输入路径

1. 通过标题的“自然挖填实验”进入，等待真实会话及首块已发布远景，确认默认全岛相机和帧推进。
2. 实际点击回家、全岛、缩放按钮，使用鼠标拖动/滚轮或触摸拖动/双指缩放；当前局部地形发布后，玩家选择的相机仍保留。只读检查局部就绪，不为了这一步等待全部背景地形。
3. 仅在家园附近现有资源中寻找可用地块，最多检查半径32内48个资源格、8个规则允许候选和3个实际镜头目标。通过真实显示/拾取确认遮挡与就绪，不使用固定屏幕坐标猜测。
4. 选择挖地模式并拖动实际工具，检查与只读规则预览一致的地形检查点和真实土石掉落；逐个点击实际掉落并明确拾取，核对库存增加。
5. 仅用上述挖掘所得材料填筑一次。若首层不足，最多再挖两层并拾取。无法实际完成填筑必须失败，不能跳过后宣称完整通过。
6. 通过设置明确保存，要求新的成功反馈和实际存档时间推进；刷新页面、经标题重新进入 v6，核对地形、库存、掉落、资源、工具及实体，再确认已编辑地面的实际发布高程。

只读场景检查和 `session.preview` 用来选择目标与核对结果。它们不执行命令、不改存档、不调整游戏时钟、不补充库存。所有实际状态变更都通过鼠标/触摸交互。局部判定仍使用真实已发布的地形和对象拾取；不放宽未就绪目标。

## 有界失败与证据

创建上下文和页面各有15秒上限。v6 每组交互有独立的5分钟总时限，原有检查每组6分钟；这只是防挂起，不是加载或性能达标线。超时关闭测试上下文，诊断读取、截图和关闭也有短时限。v6 失败记录阶段、异常、最后可取得的场景/保存信息及截图，不把失败改成跳过成功。CI 原有25分钟总时限未修改。

## 执行和验证边界

固定的官方 Cocos 引擎/Effect 编译器和依赖就绪后，先构建领域代码和独立预览，再在实际支持 WebGL 的环境运行 `node scripts/preview/capture.cjs`。浏览器仍开启 sandbox，保留原有软件 WebGL 参数；软件渲染通过不代表硬件 GPU 或手机性能通过。不得为通过而关闭存档锁、换渲染器或绕过环境限制。

新增 Node 测试只验证读档路由、分页、时间限制和只读验收助手的行为。这些测试使用明确的隔离替身，不启动浏览器，不计入图形通过。本环境尚未运行新的实际浏览器路径；最终以对应源码提交的真实运行日志、截图和结果为准。仅生成脚本或成功打包不等于验收完成。

本次未推送、公开分支、部署或读取用户真实存档。公开远端验收分支需要另行取得用户授权。Android 原生存档工作不在此范围内。
